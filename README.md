# AP Tech Master - 応用情報テクノロジ完全攻略ラボ＆クエスト

応用情報技術者試験（AP）の最重要・最難関分野である**テクノロジ系（特に苦手になりやすいデータベース＆ネットワーク分野）**を、**「語源・背景ストーリー・動的シミュレーション・午後記述ロジック」**によって楽しく深くマスターするためのWebアプリケーションです。

---

## 🎯 開発の背景とターゲット

- **対象者**:
  - 基本情報技術者試験（FE）合格済み
  - **非エンジニア**（プログラミングやインフラ構築の実務経験はないが、ITの本質を深く理解したい方）
  - 過去問演習で `ストラテジ系 ＞ マネジメント系 ＞ テクノロジ系` となり、特に**データベース**と**ネットワーク**の克服が急務な方
- **解決する課題**:
  - 意味のわからない英字略称（RDBMS, B-Tree, ACID, 2PC, CIDR, ARP, OSPF, NAPT 等）の暗記地獄から解放
  - 午前問題の網羅的演習（全37問：DB16問＋NW16問＋基盤5問）による確実な午前突破
  - 午前知識をそのまま午後の記述問題で得点源にするための論理フレーズ・チートシート整備
  - スマートフォン片手にスキマ時間（通勤・通学・就寝前）で「なるほど！」と腑に落ちる直感UI

---

## 🚀 主な機能と特徴

### 1. 📝 午前テクノロジ完全攻略ドリル (Morning Drill) ★大幅強化！
データベースとネットワークの頻出論点を全問網羅した**全37問**の本格特訓ドリル：
- **🗄️ データベース特化（16問）**:
  - 第1〜第3正規化・ボイスコッド正規形（BCNF）
  - 関係代数演算（選択・射影・結合・直積）
  - 外部キー制約・CASCADE/RESTRICT
  - SQL集約・GROUP BY / HAVING 評価順序
  - EXISTS述語と相関副問合せ
  - 外部結合（LEFT OUTER JOIN）とNULL処理
  - トランザクションACID特性
  - 分離レベル（Dirty Read, Non-repeatable, Phantom Read）
  - 排他制御（Sロック/Xロックの互換性）
  - 2相ロッキングプロトコル（2PL）と直列可能性
  - WALログとチェックポイントによる障害回復（REDO/UNDO判定）
  - メディア障害（磁気ディスク破損）のリストア・ロールフォワード
  - B+木インデックスの構造と範囲検索
  - 2相コミットプロトコル（2PC）
  - CAP定理とNoSQL（結果整合性）
- **🌐 ネットワーク特化（16問）**:
  - OSI基本参照モデルと各層プロトコル（PDU）
  - CIDRサブネットマスク計算（/26ホスト数等）
  - VLSM（可変長サブネットマスク）最適設計
  - プライベートIPアドレス予約範囲（RFC 1918）
  - 静的NAT vs NAPT（IPマスカレード）の決定的差異
  - ARP通信手順（ブロードキャスト要求とユニキャスト応答）
  - ICMPとtracerouteのTTL減算ロジック
  - TCP 3ウェイハンドシェイクとシーケンス番号
  - TCPスライディングウィンドウとフロー制御
  - TCP vs UDP の決定的対比とプロトコル選定理由
  - ルーティング最長一致（ロンゲストマッチ原則）
  - 動的ルーティング（RIP vs OSPF vs BGP）
  - DNS階層構造とレコード（A, AAAA, MX, CNAME, PTR, TXT）
  - DHCP 4ステップとルータ越えリレーエージェント
  - タグVLAN（IEEE 802.1Qトランクリンク）
  - 回線伝送時間と回線利用率計算（Byte→bitの8倍換算）
- **⚙️ その他重要基盤（5問）**:
  - キャッシュ実効アクセス時間、パイプラインハザード、LRUページ置換、RAID 5、ハイブリッド暗号
- **充実の演習支援機能**:
  - **サブトピック別タグ絞り込み**: 「正規化」「SQL」「トランザクション」「CIDR/IP」「ルーティング」等でピンポイント特訓
  - **📋 問題一覧パレット**: 全問の正解・不正解・未着手状況をカラーグリッドで可視化、ワンタップジャンプ
  - **リアルタイム正答率メーター**: 苦手なDB・NWの克服進捗をパーセント表示
  - **要復習ストック＆ブックマーク**: 間違えた問題だけを自動蓄積して反復演習

### 2. 🔤 語源・誕生ストーリー事典 (Etymology Dictionary) ★24用語へ拡充！
非エンジニアの最大の武器である「文脈理解」を活かし、英単語の直訳と先人のドラマから本質を腹落ち：
- **DB**: RDBMS, B+木, BCNF, 2PC, CAP定理, ACID, WAL
- **NW**: CIDR, DHCP, ARP, ICMP, NAT/NAPT, TCP/UDP, OSPF/RIP, DNS, VLAN
- **その他**: RAID, MTBF/MTTR, DMA, LRU, CISC/RISC, PKI/CA, SPF/DKIM/DMARC, WAF

### 3. 📖 午後記述ロジック集 ＆ チートシート (Logic & Cheats)
- **30〜40字の記述黄金フレーズ**:
  - デッドロック防止のロック順序統一、B+木が範囲検索に強い理由、2相ロックの直列可能性保証、ハイブリッド暗号の採用理由、DNSSEC、VLANの利点、スライディングウィンドウの利点、NAPTのインバウンド遮断理由など
- **重要チートシート**:
  - トランザクション分離レベルと発生現象マトリクス
  - TCP vs UDP 決定的対比表
  - サブネットマスク＆ホスト数早見表（/24〜/30）
  - 実効アクセス時間・稼働率・伝送時間計算公式

### 4. 🧪 体感ビジュアル・ラボ (Interactive Simulators)
1. **🗄️ DB正規化ステップパズル**: 更新時異状の悲劇を目撃し、第1〜第3正規形へテーブルを綺麗に分離
2. **🌐 サブネットマスク＆CIDR計算機**: 32ビットの境界線（/24〜/30）をスライダーで操作しホスト範囲を瞬時に計算
3. **⚡ パイプライン＆フォワーディング**: 5段分業の仕組みとRAWハザード解消
4. **🔐 公開鍵・署名・ハイブリッド暗号**: アリスとボブで直感理解するTLS通信
5. **🧠 仮想記憶 LRU / FIFO ページ置換**: 時間的局所性の原理を目撃
6. **💾 システム稼働率＆RAID 5復元**: 直並列の確率計算とXOR復元

### 5. 📱 クリーンなモバイルファーストUI
- スマートフォンの親指操作に最適化されたボトムナビゲーション。
- PCブラウザでも中央にすっきり収まるレスポンシブコンテナ設計。
- 学習記録、クリア状態、EXPはブラウザの LocalStorage に自動保存。

## 🏃 起動方法

本アプリはビルド不要・環境構築不要の完全静的SPAです。

### 方法1: ブラウザで直接開く
`index.html` をダブルクリック（または右クリックして「ブラウザで開く」）するだけで即座に動作します。

### 方法2: ローカルHTTPサーバーで起動（推奨・スマホ実機アクセス可能）
Node.js がインストールされている場合、プロジェクトのルートディレクトリで実行：
```powershell
npx serve .
```
表示されるローカルIPアドレス（例: `http://192.168.x.x:3000`）に同一Wi-Fi内のスマートフォンのブラウザからアクセスすれば、スマホ実機でそのまま学習できます！

## 📚 非エンジニアのためのAPテクノロジ攻略の心得

1. **略称に出会ったらまずフルスペルを調べる**:
   アルファベット3〜4文字を丸暗記しようとすると脳が拒絶します。「英単語の直訳」を見るだけで8割の仕組みが分かります。
2. **「何が困ってこの技術が生まれたのか」を押さえる**:
   技術はすべて「先人が直面したトラブルの解決策」です。トラブルの文脈さえ掴めば、午後の長文問題はスラスラ読めるようになります。
3. **午後は「セキュリティ＋DB＋NW/システム構成」を狙う**:
   コードを書く問題（プログラミング）を無理に選ぶ必要はありません。論理的読解力とメカニズムの理解があれば、セキュリティ（必須）とデータベース、ネットワーク、システム構成で高得点を叩き出せます！
